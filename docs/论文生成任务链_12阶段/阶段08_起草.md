# 阶段 08 · 起草（对齐 SciForge Phase 12 / 13）

> 定位：把素材包"翻译"成符合 venue 规范的学术文本，同时不泄漏流水线痕迹、不越级措辞、引用真实可追溯。含 5 个子步骤：写作前硬门→章节规划→逐节装配→全稿组装清洗→编译。

## 1. 处理的问题（事实）

- `quality-gate`：**"The agent's own assessment of its work is the least reliable signal. The quality gate replaces self-assessment with objective, verifiable criteria that the agent cannot fudge."**
- `paper-writing`：五模式章节集 + elsarticle 全稿组装，**"No hallucinated content — all equations, numbers, and claims trace to research artifacts"**；正文中的管线痕迹会导致 desk reject。
- `paper-compile`：**"This check is a hard wall — there is no WARN downgrade, no 'compile anyway and flag it'."**

### 原始 prompt 原文（逐字）

**8-0 quality-gate**
- "If a check can be answered with a file read + field parse + comparison, it MUST be resolved deterministically. Never invoke LLM reasoning for these."（Type D）
- "Semantic checks MUST cite specific evidence locations (file + section/line). Never accept 'looks reasonable' as a verdict"（Type S）
- "the agent re-reads claims and evidence from scratch, without relying on memory of having produced them."
- "Hard gate. If FAIL, paper writing is blocked — no soft passes."

**8-1 paper-modes**
- "Mode determines WHICH sections exist, not their content."
- "sections contains no unknown section names."；5 合法 mode：theory-only/computational/theory+experiment/empirical/survey（原文另给 `pure_theory/derivational/...`，以规范 token 为准）

**8-2 逐节写作指令（paper-writing，用户重点关注）**
- 全局："Every claim has support — either a citation to verified literature OR a derivation/verification artifact"；"The unified elsarticle template is loaded — never hand-write the preamble"
- Title："Descriptive, not flashy" / "Contains the key technical term" / "≤ 20 words"
- Abstract："Context → Problem → Approach → Result → Implication" / "No citations (self-contained)"
- Introduction："Start with the broad scientific context" / "Narrow to the specific problem" / "State the gap clearly" / "List contributions explicitly" / "End with the paper structure roadmap"
- Intro 负面纪律："the contributions list includes ONLY results that positively support the main thesis (claims with polarity: positive)... any polarity: boundary or polarity: negative entry... → self-review FAIL (reason_code: negative_result_as_contribution)"
- Intro frontier："If FRONTIER_GAP.md is absent, the Introduction MUST emit the marker [needs-frontier-positioning] at each of those 3 points and the paper verdict is downgraded to WARN"
- Related Work："Group by theme, not by paper" / "Only cite verified papers from references.bib" / "No 'prior work is limited' without evidence"
- Problem Formalization："Do NOT reference the internal Q-id identifier, INV-G1, or any pipeline anchor in the manuscript text — the reader sees a research problem, not a pipeline run"
- Theory："Present the derivation results in neutral academic prose"；"Reproducibility is expressed as a neutral statement..., NOT as internal pipeline paths."
- Results："Present verification results in neutral academic language..., NOT as audit-skill jargon..., NOT as internal verdicts ('Type I LEAKY', 'Type IV ESCAPE', 'INV-G1 freeze verified', 'Phase 6 derivation')"
- Discussion："Honestly discuss limitations (especially any WARN verdicts from /leakage-audit or /result-to-claim)"
- References："Every reference must be cited in the body" / "Auto-generated from .bib via \bibliography{references} — never hand-edit"
- voice："Every sentence in the abstract and conclusion that states a result MUST be traceable to a claim in CLAIMS_FROM_RESULTS.md that PASSED at the fidelity quoted."

**8-3 清洗门**
- 8 类（表格实列 A–I 九类）regex 清洗：内部路径 / phase jargon / audit verdicts / pipeline identifiers / caption 渲染管线 / 内部 config / draft comments / frontmatter leak / 工具品牌泄漏。须 `hits_remaining=0` 才 PASS。

**8-4 paper-compile**
- "auto-fix any compilation errors, enforce a zero-warnings policy, verify page count against the OSS unified target, and confirm submission readiness."
- "ALL LaTeX output must be warning-free. Overfull/underfull hbox, undefined references, citation warnings, and font embedding warnings must ALL be resolved before declaring success."
- "Never delete the user's source files — only modify to fix errors."；"Don't suppress warnings — FIX all warnings"
- "Do NOT loop on the same warning for more than 2 attempts"

### 推理逻辑（解释）
法条层（paper-modes 定"写哪些节"、discipline-writing 定"怎么写"、voice/language/writing-principles 定"用什么语气和纪律"）注入 paper-writing 的逐节生成；result-to-claim 的 fidelity 通过 voice contract 约束措辞（symbolic→proven / numerical→supported / qualitative→suggests）；清洗门把工程脚手架路径从正文剔除；编译门做零警告硬墙。

## 5. 门与有界回退

| 子步骤 | 门 | 阈值 | 失败去向 |
|---|---|---|---|
| 8-0 | 停滞 | `RETRY_COUNTERS > MAX_RETRIES` | STAGNATED FAIL → 阻断，建议放弃方向 |
| 8-0 | QF-G1~G7 | 任一 FAIL | BLOCKED（G8/G9 允许 WARN） |
| 8-0 | SD-G1~G5 | 任一 FAIL | FAIL → reframe claims |
| 8-1 | mode 合法 | 5 mode；`_FOUND` 占位符 | BLOCKED |
| 8-2 | claim 锚 | 每个引用 claim `resolved:true` | `claim_anchor_broken` FAIL |
| 8-3 | leakage scrub | `hits_remaining=0` | BLOCKED `pipeline_leakage_not_scrubbed`，拒编 |
| 8-3 | 图预算 | <7 WARN / <5 FAIL；缺架构图 FAIL | 重写/补图 |
| 8-3 | AIGC 黑名单 | 任一 class ≥6 | FAIL `aigc_phrasing` |
| 8-3 | 阴性结果 | boundary/negative 混入 contributions | FAIL `negative_result_as_contribution` |
| 8-4 | scrub 状态 | status=PASS | `BLOCKED: leakage_scrub_gate_not_run` |
| 8-4 | 页数 | short≤6 / standard≤12 / long≤16 | FAIL `page_limit_exceeded` → 回 8-1 |
| 8-4 | 零警告 | 每 warning ≤3 次（按 warning 计） | 第 3 次 BLOCKED，仅用户可豁免 |
| 8-4 | 图嵌入 | --min-figures + --require-renderer，exit 2 | FAIL `figures_not_embedded` |

**有界回退**：STAGNATED / QF-G1~G7 FAIL / SD FAIL → 阻断写作；leakage scrub FAIL → 重写命中至零；超页 → 经 paper-writing loop-back 移证明到附录、压表格后重编；同一 warning 3 次未解 → BLOCKED（仅用户可豁免）。

## 6. 事实 / 解释 / 不确定
- **事实**：19 项硬门阈值、逐节写作指令原文、fidelity→措辞映射、九类清洗正则、零警告策略。
- **解释**：把 8-2 逐节装配作为用户重点——每个 claim 都拉通 Claim/Evidence/CitedPaper/FigureAsset/SectionPlan 五类节点。
- **不确定**：`paper-writing` Step 3.5 自称 "8-class regex" 但表格实列 A–I 九类（I 为 v1.4.0 新增）；`paper-compile` Max pages=15 与 tier cap（6/12/16）并存，按 tier cap 引用更准确。两处均为原文内部不一致，已登记。
