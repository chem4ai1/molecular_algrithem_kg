# 阶段 05 · 新颖性与人择（对齐 SciForge Phase 3 / 4targeted）

> 定位：DAG 剪枝门。对想法做四维评估和碰撞审计，定位 frontier baseline / delta / why-not-before，收敛到**至多 1 个 survivor**。**强制人工检查点，agent 不能自己选。**

## 1. 处理的问题（事实）

**"Non-negotiable goal: at most 1 idea survives to the derivation phase. The DAG converges to a single path."**

产出可追溯的贡献定位三元组，避免 paper-writing 在 Intro 临时编造。**"The delta must be falsifiable — if delta is 0 or negative after the idea runs, the Phase 14 kill-argument will catch it."**

## 2. 输入

### 原始 prompt 原文（逐字）
- "at most 1 idea survives to the derivation phase"
- "Never write 'no research exists to our knowledge' — that is empty talk; be specific: '[Smith2024] reached X, [Lee2025] improved to Y, but Z remains unsolved'."
- "collision ≠ death sentence; handle by the strictest hit"
- "idea FAILs directly — this is reproduction, not research"
- 计分公式："novelty_final = 0.5 × binary_novelty + 0.5 × frontier_advance"；"score = novelty × 0.45 + feasibility × 0.25 + relevance × 0.15 + engineering_grounding × 0.15"
- 四 verdict："PASS — proceeds to the next phase" / "FAIL — eliminated immediately (reason recorded)" / "REVISE — sent back to idea-discovery for refinement (max 2 rounds)" / "PENDING — insufficient information; human judgment needed"

### 推理逻辑（解释）
targeted 波次先针对 survivor 补检索 → 4 轴加权重评（注意本 skill **不重算**预筛轴，只做 survivor selection）→ 碰撞矩阵（same_problem/method/data 三维 0/1）→ frontier 三元组抽取 → 唯一 survivor 交人工裁决。这一步把"贡献定位"变成可核验的引用链。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| 复合分 | 0.45/0.25/0.15/0.15 加权 | <0.6 eliminated | 淘汰 |
| binary novelty | 打分 | ≥7 novel；4–6 partial；<4 not_novel | not_novel 直接 FAIL |
| frontier_advance | 缺 baseline ≤4；delta 不可证伪 -3；落在 solved node =1 | — | 扣分 |
| why-not-before | 条目数 | <3 → `why_not_before_weak`，扣 2 分 | — |
| 碰撞矩阵 | 三维全 1 | collision_fatal FAIL | 回 Phase 2 |
| 三元组门 | FRONTIER_GAP 缺 1 项 | → WARN | 不能进 Phase 3→4 checkpoint |
| 复审门 | REVISE | ≤2 | 超限 BLOCKED |
| 无 survivor | 放宽 strictness 一次仍无 | — | BLOCKED 需人类介入 |

**有界回退**：REVISE → `/idea-discovery` 精化 ≤2 轮；无 survivor → 放宽 strictness 一级（≤1 次）；`gap_anchor_invalid` → FAIL 回 Phase 4broad；Phase 3→4 是**强制人择检查点**。

## 6. 事实 / 解释 / 不确定
- **事实**：0.6 复合门槛、0.45/0.25/0.15/0.15 权重、碰撞三维规则、REVISE≤2、人择检查点。
- **解释**：三元组（baseline/delta/why-not-before）是阶段 8 Intro 的直接素材，所以本阶段的产物质量决定写作阶段是否要发 `[needs-frontier-positioning]` 标记。
- **不确定**：`frontier_advance` 的扣分细则（-3、=1）是从原始文档提取的具体数值，与整理文档一致；"collision_fatal FAIL 回 Phase 2"的回退目标在整理文档与原始文档表述略有差异（Phase 2 vs Phase 4broad），按原始 skill 以 Phase 2 为准。
