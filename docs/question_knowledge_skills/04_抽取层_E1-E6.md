# 04 · 抽取层（E1–E6）的问题与改动

> 现有：每阶段「词表 + 阶段契约 + 模板」，`NON_LLM` 只在代码侧校验、不进 prompt；
> 6 阶段合计约 8395 字符。以下改动都在此基础上增量。

## 4.1 四个要解决的问题

| # | 问题 | 现状证据 | 影响 |
|---|---|---|---|
| A1 | 证据只到句子，不到论断 | `relations[].evidence` 是逐字串，但没记录「支撑条目的哪一半」 | 引用审计无法判断「这段是否真支撑」 |
| A2 | 未区分「原文说的」与「模型复述的」 | 报告的 `paradigm.relations` 有 `grounded` 标记，但 E1–E4 输出无 provenance 分栏 | 一旦 LLM 改写，无法回溯 |
| A3 | 数值缺实验条件 | `model_results[]` 只有 5 个字段（model/metric/value/unit/is_sota） | evidence_sufficiency 五项全部无法算 |
| A4 | 模块无「创新组件」标记 | `AlgorithmModule` 有 inputs/outputs，无 novel 标记 | 消融无法从图中枚举 |

## 4.2 六处 prompt 改动（对应主表 P1/P2/P3/P4/P5/P6/P7/P8/P9/P10）

### E1_paper（2 处）

```
新增字段：
  problem_anchor_id  = "Q-<arxiv_id>"      # 冻结，后续全链回引
  evidence_norm      = 枚举（validity|accuracy|f1|perplexity|docking_score|...）
新增约束：
  「若标题与研究陈述冲突，以摘要中的研究陈述为准」
```

### E2_algorithm（2 处）

```
新增字段（Algorithm 级）：
  assumptions[] = 该方法成立的前提（数据独立同分布/单峰分布/无标签泄漏…）
新增字段（Module 级）：
  is_novel_component = true|false
  component_role     = backbone|encoder|decoder|loss|sampler|其他
禁止项：
  「不要把所有模块都标为 novel；只标论文明确声称的新组件」
```

### E3_benchmark（2 处）

```
新增字段：
  protocol = {seeds:int|null, split:str|null, eval_script:str|null,
              epochs:int|null, hardware:str|null}
  metrics[].contribution_link = 该指标度量哪个贡献（≤20 字）
禁止项：
  「'we follow the standard split' 不是 split 值，填 null」
```

### E4_values（2 处）

```
新增字段：
  outcome_class = primary|secondary
  seeds         = int|null（原文写 "3 runs" → 3；未提 → null）
  sample_size   = str|null
  train_scale   = str|null
禁止项：
  「不得用 unit 承载方差；± 值写入 value_note」
  「不得把表格里的多列拼成一个 value」
```

### E5_relations（1 处）

```
新增字段：
  relations[].context = 该引用/工具支撑的原文句子（逐字，≤120 字）
用途：引用审计的 context 层输入
```

### E6_lineage（1 处）

```
新增字段：
  assumption_delta = 相比父方法改进了哪条前提（≤40 字）
用途：逻辑审计判断「改进是否真的成立」
```

## 4.3 四个「不新增调用」的约束

1. **不新增阶段**：所有字段塞进现有 6 个阶段模板，避免第 7 次 LLM 调用。
2. **字段可空**：`seeds=null` 是合法值，强制填会诱导编造。
3. **长度预算**：每阶段新增 ≤ 200 字符；改后总量应 ≤ 10000（当前 8395）。
4. **校验前置**：新增字段进 `validator.py` 的枚举/类型校验，
   不合格按现有 `issues` 流程重试，不静默丢弃。

## 4.4 与范式层的关系

范式层（`paradigm.py`）已经做的事不要重复：

| 已做 | 不要在新 prompt 里重复要求 |
|---|---|
| NER 识别算法/基准/指标实体 | 不要让 LLM 再列实体清单 |
| 关系逐字落地（char offset） | 不要让 LLM 输出 offset |
| 模块追踪（step_order/depends_on/data_flow） | 不要让 LLM 输出依赖顺序 |
| 槽位审计（`slot_audit`） | 不要让 LLM 自评完整性 |

新加字段只补范式层拿不到的东西：**冻结 id、假设、协议、实验条件、主次、引用上下文**。
