# 阶段 06 · 预注册方法（对齐 SciForge Phase 5 / 6）

> 定位：在推导运行**之前**构建 8 节方法注册表，对 Section 3 加密哈希锁定并强制人工批准；再用 verification-routing 决定"实验优先 / 纯理论 / 混合"路线。把"你是看到结果后才选方法吗"变成可审计工件。

## 1. 处理的问题（事实）

**"Turn the vague reviewer question — 'did you decide your method BEFORE seeing results, or after?' — into a machine-readable, auditable, structured artifact (METHOD_REGISTRY.md) with a cryptographic hash lock."**

**"This section is the pre-registration lock. Once the user approves the registry, this section's SHA256 is recorded in REGISTRY_HASH.txt and can NEVER be modified without explicit re-approval."**

verification-routing：**"experiment-first by default — when in doubt, route by experiment."**

## 2. 输入

### 2.1 检索的知识节点
| 节点类 | 关键属性 | 来源 | 是否必须 |
|---|---|---|---|
| ResearchGap | `statement / selected_at` | Phase 5 | 必须 |
| IdeaNode | `id / falsifiable_claim / mechanism` | Phase 5 survivor | 必须 |
| Assumption | `statement / scope / applicability` | survivor 假设 | 必须 |
| DomainProfile | `evidence_type` | Phase 2 | 必须（决定路由） |
| FinalProposal | `Q-id / ProblemAnchor` | Phase 1 | 必须 |

### 2.2 检索的 schema 定义
- `application/Assumption.md`——`statement / scope / applicability / evidence`（global，本阶段产出）。
- `application/ExperimentArm.md`——`kind(main/baseline/ablation/hyperparam) / config / n_seeds / benchmark`（global，实验矩阵落点）。
- `application/Benchmark.md`（语义层）——`metrics / protocol / model_results`（决定实验矩阵设计与 fidelity）。

### 2.3 输入产物文件
`FINAL_PROPOSAL.md`、`IDEA_DAG.json`、`AGENT_DOC.md`（DISCIPLINE_CONTEXT）、`domain-signature.json`。

## 3. Skills 转移函数

| skill | 角色 | 输入 → 输出 |
|---|---|---|
| `support/method-registry` | Phase 5 MUST + 人工检查点 | survivor → 8 节注册表 + hash lock |
| `shared-references/verification-routing` | Phase 6 入口路由 | evidence_type → 三路线 |

### 原始 prompt 原文（逐字）
- "Do NOT invoke for: After derivations are run (post-hoc registration is research fraud)"
- "Do you approve this method registry? Section 3 will be locked."
- "This step cannot be skipped or self-approved by the agent."
- "Without approval: registry is `DRAFT`, downstream skills MUST reject"
- "No silent edits after approval. Section 3 is hash-locked. Any change requires re-approval."
- "The logic gap is fundamental — the implication cannot be defended under the current assumptions. Recommend returning to `/idea-discovery` to select a different approach to the problem."
- 路由："theory-only must satisfy the **double condition** (derivational ∧ no executable computation); satisfying only one still routes to experiment-first"
- "Toy quick verification (idea level): small scale (~20 rounds of training / 1-10% of data / synthetic data with known effects) verifies 'is this idea heading in the right direction' — this is a **life-or-death verdict for the idea**, not a paper experiment"
- "`na_verdicts` only grows, never shrinks"

### 推理逻辑（解释）
8 节注册表：§1 Problem / §2 假设 / §3 Method Selection（hash lock target）/ §3.5 实验矩阵 / §3.6 Evaluation Protocol / §4 结果分类 / §5–8 其他。人工批准后 SHA256 锁定；路由按 evidence_type 三选一：experiment-first（默认）、theory-only（双条件）、hybrid。

## 4. 输出

### 4.1 知识节点

- `VerificationRoute`（建议新增 global）：`route / evidence_type / na_verdicts[]`

### 4.2 产物文件
`methods/METHOD_REGISTRY.md`（8 节）、`methods/REGISTRY_HASH.txt`（SHA256 或 `BLOCKED:<reason>`）、`methods/.sciforge/APPROVAL_LOG.txt`（`INITIAL_APPROVAL`）、`METHOD_BINDING.md`、`OUTCOME_CLASSIFICATION.md`、`EXPERIMENT_MATRIX.json`、`EVALUATION_PROTOCOL.json`、`.sciforge/verdicts/VERIFICATION_ROUTING.json`。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| 审批门 | `APPROVAL_LOG.txt` 无 `INITIAL_APPROVAL` | — | DRAFT / 下游拒绝 |
| 矩阵门 | main≥1；baseline≥3；ablation≥2；hyperparam≥1×≥3 点；robustness≥3 seeds+≥1 perturbation | 缺项 | `BLOCKED: experiment_matrix_incomplete` |
| hash 格式 | `validate_verdicts.py` | 64-hex 或 `BLOCKED:<reason>` | ERROR |
| 假设健康 | Fatal assumptions reasonability | <5 → HIGH RISK | — |
| fidelity | primary 默认 | numerical（可配 symbolic/qualitative） | — |
| SA-G1/G2/G3 | 注册表完整性 | — | LEAKY on primary → BLOCKED |
| 回调门 | 同一 logic gap | ≤3 iterations | 耗尽 → DRAFT + `LOGIC_GAP_FUNDAMENTAL_ISSUE` |

**有界回退**：`/leakage-audit` 发现 primary LEAKY → callback 重调 method-registry（≤3 轮）；3 轮耗尽 → halt 并建议回 `/idea-discovery` 换方法（**Do NOT silently continue**）；hash drift → 6 步 re-approval 流程。路由一旦决定即 final，下游只读不改。

## 6. 事实 / 解释 / 不确定
- **事实**：8 节注册表、SHA256 64-hex、人工审批不可代理、实验矩阵 5 类下限、回调≤3、路由双条件。
- **解释**：把 MethodLock 视为"方法承诺"（与 Assumption 的"前提"语义不同），这是汇总建议新增节点的依据。
- **不确定**：`budget_scale=lite` 会放宽 seeds/matrix 下限但"no category removed"——具体放宽数值来自原文，引用时应标注 effort 档位。
