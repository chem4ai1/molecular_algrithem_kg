### 原始 prompt 原文（逐字）

**citation-audit 三层 reviewer prompt**
- "For every cited bibliographic entry, invoke a fresh cross-model reviewer with web/OpenAlex/arXiv/CrossRef lookup to verify (1) the cited paper actually exists at the claimed DOI / arXiv ID / venue, (2) author names / year / venue / title match canonical sources, and (3) the cited paper actually supports the claim it is being used to support."
- **EXISTENCE**："EXISTENCE: does this paper exist at the claimed DOI / arXiv ID / venue? Output: YES / NO / UNCERTAIN, with the verifying URL. Search OpenAlex / CrossRef / arXiv / the publisher site before emitting NO."
- **METADATA**："METADATA: are author names, year, venue, title correct? For each, output: correct / wrong: should be ... / typo: ..."
- **CONTEXT**："CONTEXT: for each use, does the cited paper actually support the surrounding claim? Output per-use: SUPPORTS / WEAK / WRONG, with one-sentence reasoning."
- 裁决："Emit VERDICT: KEEP / FIX / REPLACE / REMOVE" — "KEEP: entry is clean" / "FIX: metadata needs correction" / "REPLACE: cite is wrong-context, find a different paper" / "REMOVE: entry is hallucinated or unsupportable"
- "Be honest. If you cannot verify online, say UNCERTAIN; do not guess."
- "No `.bib` file mutations under any circumstance."（soft-only 硬保证）
- 闭环纪律："The audit MUST NOT close while FIX items remain unresolved... Silent carry-over of FIX items into the final manuscript is a contract violation"

**publishability-score**
- "Main-experiment-logic-in-place is the primary axis — if main experiment logic FAILs, total score capped at 0.4 (regardless of how good the other dimensions are)"
- "Scoring must be honest — no inflation for appearances"；"Scores must be traceable — every dimension score carries 1-2 sentences of rationale + evidence file paths"
- "total = 0.25 * dim1 + 0.15*(dim2+dim3+dim4+dim5+dim6)"；"if dim1 < 0.5 → verdict = NOT_PUBLISHABLE_NO_MEAN directly, skip to Step 4"

### 推理逻辑（解释）
三层引文核验用 fresh cross-model reviewer（存在→元数据→上下文），最危险的是 real paper 支撑错误论断（wrong-context）；评分以主实验逻辑为硬轴（dim1<0.5 直接封顶 0.4），其余五维各 0.15；最后编排器做产物归档与经验回放。结论回环：REPLACE/REMOVE → 回 paper-writing，评分 SUPPLEMENTARY_GAPS → 生成缺实验清单。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| citation 总判定 | 全 KEEP→PASS；仅 FIX→WARN `metadata_drift`；REPLACE/REMOVE→FAIL `wrong_context`；无 cite→NOT_APPLICABLE | — | FAIL 回 paper-writing Phase 6 |
| DOI overlap | `doi_gate.py` title token-overlap | ≥0.8 | FAIL |
| FIX 闭环 | FIX 未解决不得 close | — | 修复或声明 unfixable |
| REPLACE/REMOVE | 需人工批准 | — | 不自动应用 |
| 评分 dim1 | <0.5 → 封顶 0.4 | — | NOT_PUBLISHABLE_NO_MEAN，rethink idea |
| 评分 tiers | SUBMISSION_READY≥0.80且dim1≥0.8；SUPPLEMENTARY_GAPS 0.55–0.79；NEEDS_MAJOR_REVISION 0.40–0.54 | — | 生成缺实验清单 |
| 整体 verdict | 26 节点最差值 ERROR>BLOCKED>FAIL>WARN>NOT_APPLICABLE>PASS | — | BLOCKED/FAIL 不 finalize |
| wrap parity | method↔code / validate_verdicts --strict --require-complete | ≥80% | BLOCKED |

**有界回退**：citation FAIL → 回 paper-writing（删伪造引文、必要时回 Phase 4 重搜）→ 重编；评分 SUPPLEMENTARY_GAPS → 生成 Missing-Experiments Manifest（带 priority/effort）；dim1<0.5 → "Do not add experiments; rethink the idea/experiment design"；缺产物 → 回相关 phase。

## 6. 事实 / 解释 / 不确定
- **事实**：三层 reviewer prompt 原文、KEEP/FIX/REPLACE/REMOVE、dim1 硬轴、评分公式、tiers、整体 verdict 最差优先、parity≥80%。
