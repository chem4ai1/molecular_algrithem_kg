# 阶段 10 · 跨模型复审（对齐 SciForge Phase 14）

> 定位：单 agent 角色切换的迭代自审循环（review→fix→re-review），含 Phase B.2 领域专家盲点审和 kill-argument 反自欺。用 `effective_score=min(Phase C raw, B.2 cap)` 阻止"隐藏致命盲点换高分"的假 ready。

## 1. 处理的问题（事实）

**"never hide weaknesses to game a positive score — implement fixes BEFORE re-reviewing, document everything, and exhaust multiple solution paths before conceding any reviewer concern."**

**执行链（关键）**：**"The per-round execution order is FIXED and top-to-bottom — the agent MUST execute Phase A → Phase B.1 → Phase B.2 → Phase C → Phase D in this exact sequence each round. Skipping any phase (especially the buried B.2 sub-step) is a contract violation."**

| skill | 角色 | 输入 → 输出 |

| `shared-references/reviewer-independence` | 法条 | 定义角色隔离 |

### 原始 prompt 原文（逐字）
- "The round's final score is `effective_score = min(Phase A raw score, B.2 cap)` (see STOP CONDITION)."
- "STOP CONDITION: If `effective_score >= 6` AND verdict contains 'ready' or 'almost' → stop loop, document final state."
- "a fatal domain blind spot is submission-blocking, and a 6+ score that hides a fatal endogeneity gap is dishonest. `severe` unresolved caps at 6; `checked_clear`/`not_applicable` impose no cap."
- Nightmare 独立重推："Before scoring, independently re-derive the key claim(s) from first principles. Do NOT look at your prior derivation scripts. Write fresh SymPy code. Then compare the new result with the original. Report ANY discrepancy."
- Hard reviewer memory："IMPORTANT: You have memory from prior rounds. Check whether your previous suspicions were genuinely addressed or merely sidestepped. Be skeptical of convenient omissions in your own work."
- Round 2+："Now, as senior reviewer, re-read the updated artifacts and re-assess: 1. Score this work 1-10 for a top venue 2. Were the remaining concerns from the previous round addressed? 3. Are there new weaknesses introduced by the fixes? 4. State clearly: is this READY for submission? Yes/No/Almost"
- SCORE-ROLLBACK："if the new `effective_score` is LOWER than the previous round's, the revision is worse than no revision — roll the manuscript back to the prior version"
- S2 bar："crossing the boundary at `score ≥ 6` is the *floor*, not the target. The ScientistTwo bar is **8**... **≤ 2 rebuttal rounds**... Wording-only rebuttal = `round_invalid`... Threshold override: `SCIFORGE_REVIEW_THRESHOLD` (default 8.0)."
- Anti-Shrinkage："3 consecutive rounds without a substantive response → forced KILL path"；"if the response_class of the last 2 rounds before the final draft is all `wording` → FAIL (`reason_code: shrinkage_only_response`)"
- reviewer-independence："Re-read, don't recall — after each role switch, the agent must re-read the artifacts from files; it must not rely on in-memory recall"

### 推理逻辑（解释）
固定五阶段序列执行每一轮 → B.2 盲点审用 fatal cap=5 / severe cap=6 给 Phase C 原始分封顶 → effective_score 达标且 ready 才 STOP → 分数回退则回滚手稿 → 低于 S2 bar(8) 触发 rebuttal plan（≤2 轮）→ 3 轮纯 wording 强制 KILL。核心是"用结构化角色切换 + 证据重读"替代不可信的自评。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| STOP | effective_score≥6 且 ready/almost | 6 | 否则继续修 |
| phase14 | last_score | ≥6 | <6 → L10 回 Phase 6，≤4 轮 |
| 盲区封顶 | fatal cap=5；severe cap=6 | 5/6 | 覆盖 raw score |
| rebuttal | SCIFORGE_REVIEW_THRESHOLD | 8.0 | <8 → REBUTTAL_PLAN ≤2 轮 |
| 轮次 | MAX_ROUNDS | 4（Configuration；Quick Reference 写 3，见不确定） | 超限 BLOCKED |
| Anti-Shrinkage | 连续 3 轮无实质响应 | — | 强制 KILL path |
| 分数回退 | 新一轮分更低 | — | 回滚手稿，记 `round_rolled_back:true` |
| fatal 盲点 | 存活到 MAX_ROUNDS | — | `BLOCKED: unresolved_domain_blindspot_<mode>` |

**有界回退**：`experiment_redesign`→Phase 6 rollback；`PIVOT`→Phase 5 rollback（继承≤2）；`KILL`→Phase 2 rollback；fidelity gate BLOCK 是硬覆盖不可用顶层 verdict 推翻。

## 6. 事实 / 解释 / 不确定
- **事实**：五阶段固定序列、effective_score 公式、fatal cap=5/severe cap=6、S2 bar=8、≤2 rebuttal、MAX_ROUNDS=4、SCORE-ROLLBACK。
- **解释**：把 B.2 盲点审理解为"用领域失败模式（FailureMode 节点）给自评打分封顶"，是把 schema 节点用进判定逻辑的典型。
- **不确定**：MAX_ROUNDS 文件内部不一致——Configuration 写 4，Quick Reference 写 3（原始提取已标）。引用以 Configuration 的 4 为准并注明冲突。`last_score` 是状态字段名，STOP 实际用 `effective_score`（整理文档曾写 last_score≥6，已纠正）。
