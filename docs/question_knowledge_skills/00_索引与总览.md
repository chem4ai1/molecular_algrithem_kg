## 0.3 关键判断：SciForge-OSS 是「无实验版」，我方是「有实验版」

`leakage-audit` 明写 Type II（隐藏违规）与 Type III（代理不匹配）
在 OSS 中 `NOT_APPLICABLE`，因为 OSS「没有 discipline-specific 假设、没有 benchmark」。
但**我方正好有 benchmark、指标与数值**，这两类恰恰必须启用。

同理，OSS 删掉了 main SciForge 的 **cs-ml 不变量**：

```
INV-C1 BENCHMARK_PROTOCOL_LOCK
INV-C2 ABLATION_COMPLETENESS
INV-C3 SEED_STRATEGY_LOCK
INV-C4 LEAKAGE_AUDIT_VERDICT
```

这四条是我方（ML 论文复现）应当启用的，而不是照抄 OSS 的 `INV-G1` 单条。
