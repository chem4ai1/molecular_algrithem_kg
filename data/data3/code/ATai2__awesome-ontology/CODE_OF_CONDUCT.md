# 贡献者行为准则

本项目采用 [Contributor Covenant](https://www.contributor-covenant.org/) 2.1 版行为准则，以下为中文摘要，完整文本以英文原文为准：https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## 我们的承诺

无论年龄、体型、可见或不可见的缺陷、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性取向如何，我们作为成员、贡献者和领导者，承诺让每个人参与本社区都不受骚扰。

## 我们的标准

有助于创造积极环境的行为包括：对他人保持同理与友善；尊重不同的观点、看法和经验；给予并优雅接受建设性反馈；承担责任，向受我们错误影响的人道歉，并从中学习；不仅关注对个体最好的事，也关注对整个社区最好的事。

不可接受的行为包括：使用带有性暗示的言语或图像，以及不受欢迎的性关注或挑逗；挑衅、侮辱或贬损的评论，以及人身攻击或政治攻击；公开或私下的骚扰；未经明确许可公布他人的私人信息，例如住址或电子邮箱；其他在专业场合有理由被认定为不适当的行为。

## 执行

社区领导者有责任解释并执行我们对不可接受行为的标准，并对任何其认为不当、威胁、冒犯或有害的行为采取适当而公正的纠正措施，包括暂时或永久移除相关成员资格。

若你遭遇或目睹不可接受的行为，请通过 Issue 或向项目维护者私密联系举报。所有投诉都会被审阅与调查，并及时作出必要且适当的回应。社区领导者有义务对事件报告者的信息保密。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共空间代表本项目或其社区时的行为。
