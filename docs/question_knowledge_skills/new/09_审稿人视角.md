# 09 · 审稿人会怎么打

第九个必须回答的问题：**如果我是审稿人，我会在哪一句停下？**

## 9.1 阅读顺序（决定你该把力气花在哪）

```
标题 → 摘要 → 引言 → 图 1 → 其余
```

- 前两页不清楚，后面再精彩也没人看
- 力气分配：摘要 / 引言 / 图表 / 其余 各约 25%

## 9.2 最有效的自检：先写最强反驳

不要写「本文有什么优点」，要写**「如果我要拒这篇，最强的理由是什么」**，
然后逐条回应。这一步比任何润色都有效。

典型的最强反驳：

| 类型 | 反驳 |
|---|---|
| 新颖性 | 这就是 A + B，A 和 B 都是现成的 |
| 有效性 | 涨点可能在 seed 噪声范围内 |
| 可比性 | baseline 没调参 / 没复现 |
| 归因 | 没做消融，不知道是哪部分起作用 |
| 泛化 | 只在一个数据集上验证 |

## 9.3 六维可发表性打分

| 维度 | 问的问题 | 低分表现 |
|---|---|---|
| 新颖性 | 与最近工作差在哪 | 增量组合 |
| 有效性 | 证据是否支撑结论 | 单 seed、无 baseline |
| 严谨性 | 消融与统计是否完整 | 缺消融、缺方差 |
| 影响力 | 谁会因此改变做法 | 只对细分任务有用 |
| 可复现 | 别人能否重跑 | 缺代码/缺协议 |
| 表达 | 前两页是否清楚 | 摘要空泛 |

## 9.4 审稿意见的正确处理

分三类，处理方式不同：

| 类型 | 处理 |
|---|---|
| 事实错误（引错、数错） | 直接改，无需辩解 |
| 证据不足（要求补实验） | 能补就补；补不了就降级措辞，不要硬撑 |
| 理解分歧（审稿人误读） | 先改表述，再解释；不要先指责审稿人 |

禁止：把「证据不足」的批评改写成「我们做了探索性分析」—— 这是换词不换事实，
复审会被同一问题再打一次。
