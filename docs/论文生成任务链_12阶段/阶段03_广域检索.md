# 阶段 03 · 广域检索（对齐 SciForge Phase 4broad）

> 定位：`MUST`，从不跳过。多源学术搜索 + 三层反幻觉验证 + 广域波次挖掘 `GAP_REPORT.md`。**只检索、验证、格式化元数据，不解释论文内容。**

## 1. 处理的问题（事实）

**"This is the anti-hallucination meta-skill: every citation in the final output must have a real, verifiable academic source. No paper is ever fabricated from memory."**

产出 gap 报告供想法生成锚定；gap 必须带已验证引用。**"Never write 'no research exists to our knowledge' — that is empty talk; be specific: '[Smith2024] reached X, [Lee2025] improved to Y, but Z remains unsolved'."**

## 2. 输入

### 2.1 检索的知识节点
| 节点类 | 关键属性 | 来源 | 是否必须 |
|---|---|---|---|
| SearchQuery | `research topic / sub-topics / wave mode(broad)` | 用户/问题 | 必须 |
| ResearchQuestion | `research_question / problem_category` | Phase 1 | 必须 |
| Paper（种子） | `arxiv_id / doi` | 用户提供 | 可选 |
| Retrieval 配置 | `sources / min_year / max_papers / verification_level` | 配置 | 必须 |

### 2.2 检索的 schema 定义
- `semantic/Paper.md`——检索到的论文落为 `Paper` 节点（`title / arxiv_id / doi / year / venue`，注意 `doi / venue` 填充率 0%，本阶段应回填）。
- `application/SourcePaper.md`——出处论文（`title / ref_paper / relation / resolved`，来自科技树）。
- `application/ResearchGap.md`——`gap_type / statement / evidence / priority / source_papers`。
- `application/CitedPaper.md`——`cite_key / layers / existence / metadata_ok / context_ok`。

### 2.3 输入产物文件
Search query、`refine-logs/FINAL_PROPOSAL.md`（core claim coverage）、`literature/.proxy-resolved.json`、`literature/.pending/`。

## 3. Skills 转移函数

| skill | 角色 | 输入 → 输出 |
|---|---|---|
| `meta-skills/universal-retrieval` | Phase 4broad MUST | query → 文献库+GAP_REPORT+bib |

### 原始 prompt 原文（逐字）
- "The 3-layer anti-hallucination protocol is mandatory"
- "Every paper in the output carries a real-existence verification tag — no paper is included on faith"
- "No paper is silently dropped — every candidate paper is either verified or explicitly marked unverifiable"
- "every gap carries ≥1 verified cite key from `references.bib` (no gap may rest on an unverified or absent paper — the 3-layer protocol applies to gap evidence too)"
- 数据源："all external API calls (arxiv export, S2 graph, crossref works, pubmed eutils, openalex) **must go through the proxy**"
- "Strictly forbidden: skipping any of literature search, filter-chain integrity audit, or dataset downloads due to network problems. Network issues may only downgrade the verdict from `PASS` to `WARN` — never to `SKIP`/`NOT_APPLICABLE`/`BLOCKED` for network reasons."

### 推理逻辑（解释）
broad 波次：6 源检索（arXiv→S2→CrossRef→PubMed→Web→OpenAlex）→ 三层验证 → 近因检查 → filter-chain 完整性 → 按 `gap_type ∈ {contradiction, unsolved_node, method_blank, data_blank, generalization_blank}` 归类出 GAP_REPORT。gap 是后续想法生成的锚，所以"gap 必须有已验证引用"是硬约束。

## 4. 输出

### 4.1 知识节点
- `Paper`（global，title/authors/abstract/PDF URL/DOI/arXiv ID）
- `SourcePaper`(global)、`ResearchGap`(task-w)、`CitedPaper`(task-w)
- `Verification`(status/layers passed)、`GapReport`、`Audit`(recency_ratio/audit_verdict)

### 4.2 产物文件
`literature/references.bib`、`landscape_report.md`、`VERIFICATION_LOG.md`、`verified_papers.json` / `unverified_papers.json`、`GAP_REPORT.md`、`FILTER_CHAIN_AUDIT.json`。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| Layer1 | arXiv batch | batches of 40 | — |
| Layer2 | CrossRef DOI | — | — |
| Layer3 | S2 fuzzy match | ≥ 0.6 且 ≥2 元数据字段 | — |
| 总判定 | PASS≥2层 / WARN=1层 / BLOCKED=0层或fatal mismatch / ERROR=API失败 | — | 未验证不入 bib |
| 近因门 | 近 2 年占比 | ≥ 40% | 低→重检索(min_year=current-2)；仍低→`recency_gap` |
| gap 门 | `gap_gate.py`：gap-id+引用+判别词 | lite≥1 / balanced≥2 / max≥3 / beast≥4 | 回 Phase 4broad |
| proxy 门 | 不可达 | — | WARN 而非 SKIP |
| 波次完整性 | sub-direction 覆盖 N-1；无孤儿引用；年份不集中 | — | re-search ≤3 轮 |

**有界回退**：FAIL（无 core claim 覆盖 / 全部引文未验证）→ Phase 4 re-search ≤3 轮；WARN → Phase 5 继续但记 `NEEDS_HUMAN_LIT_supplement`；网络问题只降 WARN，绝不 SKIP。

## 6. 事实 / 解释 / 不确定
- **事实**：三层验证协议、40% 近因门、S2 fuzzy 0.6、gap 门分级阈值、网络只降 WARN。
- **解释**：把 6 源检索顺序理解为"arXiv 优先、OpenAlex 兜底"的优先级（原文标注 6 个数据源优先级）。
- **不确定**：原文同时出现"3 层"与"6 源"——3 层指验证深度（arXiv/CrossRef/S2），6 源指检索广度，二者是不同维度，不冲突（已在整理文档与原始文档中交叉确认）。
