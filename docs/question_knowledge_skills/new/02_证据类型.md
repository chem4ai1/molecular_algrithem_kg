# 02 · 这个领域认什么证据

第二个必须回答的问题：**我的结论要用哪一类证据支撑？**
SciForge 把证据分成有限的 6 种类型（evidence_type），每种对应不同的真值标准。

| evidence_type | 真值标准 | 验证方法 | 典型领域 |
|---|---|---|---|
| causal_inference | 因果识别成立 | 识别策略 + 稳健性检验 | 经济、社科、流行病 |
| derivational | 推导无缺口 | 定理证明 | 数学、理论物理、理论 CS |
| experimental | 可重复测量 | 对照实验 + 统计检验 | 医学、生物、心理 |
| simulational | 数值行为符合预测 | 仿真 + 收敛性分析 | 物理、气候、**ML 训练** |
| correlational | 相关性稳健 | 观测数据 + 混杂控制 | 金融、社会网络 |
| interpretive | 解释力充分 | 论证重建 + 文本分析 | 人文、法学 |

## ML 论文落在哪一类

多数 ML 论文是 **simulational**（训练/推理的数值行为）或 **experimental**（对照实验）。
区别在于说服力来源：

- 说「我的方法在这个 benchmark 上更好」→ simulational：必须给收敛性、稳定性、方差
- 说「这个干预导致效果提升」→ experimental：必须给对照、显著性、power

写错类型的典型后果：用 simulational 的证据去支撑 causal 结论（"attention 导致性能提升"），
审稿人会要求你补消融与因果识别。

## 每种证据类型对章节的硬要求

| evidence_type | 必须有的章节/小节 | 引用格式 |
|---|---|---|
| causal_inference | §4 含 Identification Strategy；§5 含 Robustness Checks；讨论内生性/选择偏差/反向因果 | author-year |
| derivational | §4 是 Main Results（定理/引理/命题）；§5 是 Proofs；无 Results 节 | numeric |
| experimental | §4 是 Methods（详细协议）；§5 是 Results（统计检验）；含 power analysis、盲法、排除标准 | numeric |
| simulational | §4 是 Model（目标函数/控制方程）；§5 是 Simulation Results（含收敛性）；含参数选择、分辨率、不确定性量化 | numeric |
| interpretive | §4 是 Argument（claim-evidence-counterargument）；§5 是 Analysis（证据权重）；显式讨论替代解释 | author-year |

## 对我方抽取的要求

这三件事必须在**抽取阶段**读出来，否则后面无从判断：

1. `Paper.evidence_type`（六类之一）—— 从方法节与实验节的写法特征判定
2. `Benchmark.protocol`（seed/划分/评测脚本）—— 决定数值证据是否可重复
3. `metrics[].contribution_link` —— 这个指标度量论文的哪个贡献

这三项是「领域认什么证据」的落地锚点，缺一项，后面的所有判定都只能靠猜。
