# 01 · 你的论文属于哪一种研究范式

做研究前必须先回答：**这篇论文的「成立」由什么决定？**
SciForge 归纳了 4 种范式，每种有自己的真值标准、验证方法与论文骨架。

| 范式 | 真值标准 | 证据门槛 | 论文结构 | 典型领域 |
|---|---|---|---|---|
| Formal | 证明无缺口 | symbolic | 主要结果 → 证明 | 数学、理论物理、理论 CS |
| Empirical | 可复现实验（统计显著） | numerical ≥ qualitative | 问题 → 方法 → 结果 → 讨论 | 医学、生物、心理、ML 实证 |
| Design | 功能可用（原型能跑） | numerical（benchmark） | 设计 → 实现 → 评估 → 讨论 | 系统、工具、工程 |
| Interpretive | 解释力（自洽、覆盖、一致） | qualitative | 主张 → 证据 → 反论 → 结论 | 人文、社科、法学 |

## 必须回答的三个问题

1. **我的贡献靠什么说服人？** 证明 / 实验数字 / 能跑的系统 / 解释力。
2. **如果没有达到这个标准，我能退到什么程度？**
   - Formal 无证明 → 降为猜想 + 证据，不能写 "proven"
   - Empirical 无数据 → 重述为理论预测，不能写 "supported"
   - Design 无原型 → 降为设计方案
   - Interpretive 无证据 → 降为假设
3. **我这篇混了两种范式吗？** 混用必须显式声明（如「定理 + 算法」= hybrid），
   否则审稿人会按更高那档要求你。

> ML 论文的常见误判：把 Design（做了个系统）当 Empirical（证明了方法有效）写，
> 结果被要求补 baseline 与消融 —— 因为 Empirical 的门槛更高。
