| 挖掘器 | 改动 |
|---|---|

| metrics | 透传 contribution_link |
| contracts | 透传 protocol 五字段 |

fidelity 计算（确定性，零 LLM）：

```python
def fidelity_of(e):
    if e.value_num is None: return "qualitative"
    if e.seeds and e.seeds >= 2 and e.has_baseline: return "numerical"
    if e.seeds and e.has_variance: return "numerical"
    return "qualitative"   # 单点/无方差/无 baseline，必须写 fidelity_reason
```

## 6.4 主张锚定 → 三档保真度

三级链现在只到「claim → 单元格 → 图节点」，需再加一维保真度：

| 档 | 判定条件 | 允许措辞 |
|---|---|---|
| symbolic | 全链推导逐步机器验证 | proven / established |
| numerical | 有重复(seeds≥2)+baseline+方差 | supported / confirmed numerically |
| qualitative | 单点、无方差、无 baseline、仅定性 | suggests / consistent with |

硬规则：primary claim 至少 numerical；symbolic-only → partial；qualitative-only → no。

## 6.6 门控改造

现有 7 门（paper_core_present → reproduction_close）全是 Type D 确定性检查。新增：

| 门 | 类型 | 条件 |
|---|---|---|
| problem_anchor_frozen | D | 每个产物都回引 Q-id，不一致即 BLOCK |
| experiment_matrix_complete | D | baseline≥3（含 naive）/ablation≥2/超参×3 |
| seed_strategy_locked | D | protocol.seeds 存在或显式声明单 seed |
| leakage_clear | D | 审计产物 verdict=pass，无 open FATAL |
| semantic_support | S | 语义判断必须引用 sau_id/node_id，不许「看起来合理」 |
| stagnation | D | 同一 blocked_by ≥3 次 → STAGNATED，阻塞后续 |

Type S 门的判据格式（强制）：
`{"verdict":"pass|fail","evidence":["<sau_id>","<node_id>"],"reason":"..."}`
缺少 evidence 字段直接判 fail，不允许裸结论。
