# P4 · 阶段 11–16：图表、写作、编译、评审、引用与可发表性

> 覆盖 26 节点：`11` unified-plotting ∥ `12` paper-writing → `13` paper-compile → `14` auto-review-loop / kill-argument → `15` citation-audit → `15.5` publishability-score → `16` 归档 + `RUN_PREPRINT` + `LESSONS`。
>
> 语义层现状（实测）：`Paper.doi` 只有 **2/808** 有值、`year` **2/808**、`venue` 0；`RELATED_TO` 只有 **48 条**且 `properties` 无 `verified`；
> `Benchmark.model_results` 只有 34% 基准有，`sota_by_metric` 14%。
> 也就是说：**这一阶段最缺的是「对外可核验性」——引用元数据几乎不存在，而图形/文本本身并不缺生成能力。**

## P4.2 一个容易忽略的因果链：`year` 缺失会击穿三层

`Paper.year` 实测 **2/808**。它不是「一个可选字段缺失」，而是三处判定的共同前置：

```
Paper.year 缺失
   ├─→ DK-P1-14 前沿是否最新      算不出  → novelty 打分失去时间轴
   ├─→ DK-P4-15 元数据一致性      比不了  → 引用审计只能做 existence 层
   └─→ DK-P4-18 可发表性主逻辑轴  证据链断 → 被评为「引用不可靠」
```

→ 所以 `year` 的补全优先级应高于 `venue`、`doi`：它是**最便宜、收益最高**的一条。

同理 `Paper.doi` 只有 2 条，意味着 `doi_gate`（strict DOI）在当前图上**必然全 FAIL**。
在补 `doi` 之前，引用审计只能用 `arxiv_id`（808/808 满）作为存在性主键——这是一个必须显式记录的降级。

## P4.3 本节小结（表外三件事）

1. **这一阶段的「知识」几乎全部是纪律，不是能力。**
   LLM 早就会画图、写引言、写 rebuttal。真正缺的是：
   图像必须绑定 claim、数字必须来自唯一真相源、措辞不得超过保真度、反驳不得虚构实验、引用必须逐字支撑。
   所以本阶段表格里 `D` 类（应用层新类/新校验）占绝大多数，**语义层只贡献 `doi / year / venue` 三个属性**。

2. **`RELATED_TO` 只有 48 条，撑不起引用审计。**
   808 篇论文平均只有 0.06 条 `RELATED_TO`。
   要做 DK-P4-14~17，引用关系必须从「图内边」扩展为「bib 级独立实体」——
   这也是本批唯一建议**在应用层新建 `Citation` 类**的地方（不进取舍：语义层不动）。

3. **kill argument 的「成立」是 gate，不是建议。**
   一旦允许「自认为反驳不成立就继续」，整个 Phase 14 就是装饰。
   `paperapp` 已把 `ChoicePoint("14")` 设为 `gate`（选项 `kill_argument_holds / reject_kill_argument`），这是正确的形状。

## P4.5 反模式

| 反模式 | 为什么错 | 正确做法 |
|---|---|---|
| 用 `Paper.title` 当逐字引文 | 标题是卖点，不是论断 | 必须用 `context_quote` + `evidence_span` |
| DOI 查不到就「软化措辞但保留 `\cite`」 | 幻觉文献仍是幻觉 | 幻觉必须删除 `\cite`；只有 context 不支撑才软化 |
| 页数超了先删图 | 图是证据，文字是叙述 | 先删冗余叙述，图只降尺寸不删 |
| 把 `publishability` 综合分当唯一判据 | 高分可以掩盖某轴 FAIL | 主实验逻辑轴 + `fairness_gate` 是一票否决 |
| `LESSONS.json` 只记成功路径 | 最有价值的是失败与人类方向的回滚 | 5 类教训必填，含 `human_hypothesis_rollbacks` |
