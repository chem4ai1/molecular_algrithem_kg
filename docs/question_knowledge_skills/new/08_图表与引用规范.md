# 08 · 图表与引用必须符合什么规范

第八个必须回答的问题：**这张图/这条引用，能支撑它旁边那句话吗？**

## 8.1 图表的四条硬规则

| 规则 | 内容 |
|---|---|
| 归属 | 主对比、主消融不进附录；删掉会削弱贡献论证的，必须在正文 |
| 复杂度 | 单图不超过 2–4 面板；超了拆图，不要堆信息 |
| 可读性 | 字号在缩放到单栏后仍可读；轴标签带单位 |
| 可复现 | 数据来源、seed、平滑窗口必须在 caption 或附录写明 |

## 8.2 引用不是「列上就行」

三层验证：

1. **存在性**：DOI / arXiv / venue 真的存在（不是模型编的）
2. **元数据**：作者、年份、venue、标题一致（版本漂移也算错）
3. **上下文**：**被引论文是否真的支撑这句话** —— 最危险的一层

第三种最隐蔽：论文是真的，但它论证的是反面。例如引 Self-Refine 来支持
「自我反馈会产生相关错误」，而原文主张的正是相反结论。

## 8.3 符号与表格

| 项 | 规范 |
|---|---|
| 符号 | 全文一致；同一符号不表示两个量；首次出现必定义 |
| 公式 | 编号连续；变量斜体、矩阵粗体；单位不进公式 |
| 表格 | 最优值加粗；方差写出；缺失值写 — 不写 0 |
| 数值 | 有效位数一致（如 99.6 与 100.0，不要 99.62 与 100） |

## 8.4 对我方抽取的要求

要在抽取阶段拿到这些信息，否则规范无从检查：

| 需要 | 从哪抽 |
|---|---|
| 图注里声明的 seed / 平滑窗口 | `Figure.caption`（当前未抽） |
| 表格里的方差与缺失标记 | `Benchmark.model_results[].std` / `null` |
| 引用的支撑句 | `RELATED_TO.context`（E5 新增） |
| 引用的 DOI/venue/年份 | `RELATED_TO.doi / venue / year` |
