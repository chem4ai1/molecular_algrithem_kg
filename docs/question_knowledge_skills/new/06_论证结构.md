# 06 · 论证结构：每章必须回答的问题

第六个必须回答的问题：**这一段在为哪个结论服务？**
删掉任何一句不推进论证的话 —— 这是最有效的写作规则。

## 6.1 摘要五句公式

1. 做出了什么
2. 为什么这个问题重要且难
3. 怎么解决的
4. 什么证据支持
5. 读者该记住的那个数

坏开头：第一句可以贴到任何论文上 → 删掉。

## 6.2 引言四段

| 段 | 内容 |
|---|---|
| 1 | 大背景 + 问题定义 |
| 2 | 已有方法与它们的局限 |
| 3 | 我们的方法 + 核心贡献 |
| 4 | 全文路线图 |

## 6.3 正文 vs 附录的归属规则

**判据**：把这个图表从正文删掉，会不会削弱某个贡献的论证？
- 会 → 正文
- 不会 → 附录

主对比、主消融**永远不进附录**；定理陈述留正文、证明可进附录。

## 6.4 篇幅预算（正文，不含参考文献与附录）

| 部分 | 预算 |
|---|---|
| 摘要 | ≤250 词 |
| 引言 | ≤1.5 页 |
| 相关工作 | ≤1 页 |
| 方法 | 按需要，但不重述动机 |
| 结果 | 1.5–2.5 页（证据核心） |
| 讨论 + 结论 | ≤1.5 页 |
| 全文正文 | 6–9 页；>12 页过长为需压缩 |

## 6.5 冗余规则

同一个结果只出现一次/一种角色：

```
摘要 = 主张；引言 = 预告；结果 = 证据；讨论 = 解释
```

跨节逐字重复 = 膨胀，要删。一句精确胜过两句含糊。

## 6.6 每个论断都要有支撑

正文里出现的每个「涨了 X」「显著」「更好」，都要能指回：
表格里的哪一行、图里的哪条线、或统计检验的哪个 p 值。
指不回去的，要么删，要么降级为 "we observe"。
