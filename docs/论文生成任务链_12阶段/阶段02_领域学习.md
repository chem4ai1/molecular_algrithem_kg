# 阶段 02 · 领域学习（对齐 SciForge Phase 1b）

> 定位：`MUST` 阶段，`domain-signature.json` 的唯一写入者。从文献、问题分析与种子论文中**从头学习**该领域认什么证据、用什么方法、怎么写、有哪些坑。

## 1. 处理的问题（事实）

从零学习领域特征（evidence_type / methodology / writing style / failure modes / evidence_norm），不硬编码。它的产物是全流水线统一消费的真值——下游 `/result-to-claim`、`/experiment-execution`、`/paper-writing`、`/publishability-score` 都读它。

**"Core principle: Do NOT pre-define domain characteristics. Search the literature, analyze the problem, and LEARN what makes this domain unique."**

## 2. 输入

### 2.1 检索的知识节点
| 节点类 | 关键属性 | 来源 | 是否必须 |
|---|---|---|---|
| Problem | `description` | Phase 1 | 必须 |
| LiteratureSearch | `Query / Results / Source` | 检索 | 必须 |
| SeedPaper | `Methodology / Structure / Citations` | 用户/检索 | 可选（优先于文献搜索） |
| SignatureHint | prior（`domain-signature-hint.json`） | Phase 1a | 可选（读取并纠正） |

### 2.2 检索的 schema 定义
- `application/EvidenceNorm.md`——`evidence_type / accepted_metrics / min_fidelity / sample_size_norm / control_design_norm / effect_reporting_norm / negative_result_norm`（当前 0 实例，本阶段填充）。
- `application/FailureMode.md`——`name / severity / detection / domain_tags`（领域失败模式目录）。
- `semantic/Paper.md`——种子论文 `Paper` 节点。

### 2.3 输入产物文件
问题描述、种子文献、`refine-logs/domain-signature-hint.json`（仅 prior）、`shared-references/domain-adaptation-guide.md`（验收规范）。

## 3. Skills 转移函数

| skill | 角色 | 输入 → 输出 |
|---|---|---|
| `meta-skills/domain-learner` | Phase 1b MUST，唯一写入者 | 问题+文献+种子 → `domain-signature.json` |

### 原始 prompt 原文（逐字）
- "Never hardcode domain characteristics. The learner starts from zero every time."
- "Seed papers > literature search when both are available. The most reliable signal."
- 四个引导问题："What are the standard methods in [domain]?" / "What are the common failure modes in [domain]?" / "What is the standard paper structure for [domain]?"
- 示例证据规范："published measurement studies typically report N >= 100 runs / >= 3 seeds; sub-50-sample results appear only as pilot notes"
- "When the survey is too thin to support a norm, the field is set to `\"unknown — defaulting to conservative\"` and consumers fall back to their built-in conservative defaults (never invent a norm)."
- 失败告警："WARNING: Domain learner could not find specific characteristics for [domain]. Using general defaults. Consider adding seed papers for better results."

### 推理逻辑（解释）
文献搜索 → 种子论文分析（优先）→ 归纳六维 profile → 置信度打分 → 低于阈值回落 general 保守默认。"证据规范"是本阶段最关键的产出——它决定后面"多少样本/几个 seed 才算充分证据"，直接喂给阶段 7 的 claim 门和实验矩阵。

## 4. 输出

### 4.1 知识节点
- `DomainProfile`(paperapp, learned，加 `origin=learned|rule` 与 `learning_confidence`)
- `EvidenceNorm`(global)、`FailureMode`(global)
- MethodologyProfile / FailureModeProfile / WritingProfile / EvidenceNormProfile（五类 profile 字段）

### 4.2 产物文件
`refine-logs/domain-signature.json`（唯一真值）、`refine-logs/domain-learning-log.md`。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| 置信门 | `learning_confidence` | ≥ 0.7 | <0.7 用默认值，不应用所学 |
| 论文数门 | `min_papers_for_learning` | 3 | <3 不可靠 |
| 零结果门 | 检索结果为 0 | — | Learning Failure Report + WARNING → general academic + 2–3 seed papers |
| 优先级门 | seed papers 与检索并存 | — | seed papers 优先 |

**有界回退**：学习失败 → 下游全部用默认行为；hint 从不被直接消费。该阶段为 MUST，失败 3 轮即 BLOCKED（pipeline-integrity 的 Phase Mode 规则）。

## 6. 事实 / 解释 / 不确定
- **事实**：0.7 置信阈值、min 3 篇、"unique writer"纪律、"never invent a norm"原文。
- **解释**：将 evidence_norm 视为阶段 7 claim 门的上游输入（这是跨 skill 约束通道的一部分）。
- **不确定**：`Phase 1a hint confidence 可 < 0.7` 而 learner 阈值是 0.7——两者定位不同（hint 是 prior），文档已明确 hint 不作为 fallback，无冲突但需要读者留意。
