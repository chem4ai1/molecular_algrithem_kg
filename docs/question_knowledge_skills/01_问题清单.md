# 01 · 要解决的问题清单

> 按我方六层框架归位。`严重度`：P0=不补会产出错误结论 / P1=显著降低可信度 / P2=增强项。
> `现状`列全部对照真实代码与产物。

## A. 抽取层（E1–E6）

| # | 问题 | 现状 | 严重度 | 来源 skill |
|---|---|---|---|---|
| A1 | **证据粒度只到句子，没到「支撑哪个论断」** | 关系有 `evidence` 逐字串，但没记录「这段证据支撑条目的哪一半」 | P1 | `result-to-claim` 的 claim↔evidence 映射 |
| A2 | **无法区分「论文说的」与「我们推的」** | SAU 的 `provenance` 有 `extracted/derived/inferred`，但抽取报告里 LLM 复述与原文事实未分栏 | P1 | `method-registry` 的 assumption 质量评分 |
| A3 | **数值抽取缺「实验条件」** | `numeric` SAU 只有 value/unit/direction，没有 seed 数、样本量、训练规模 | **P0** | `result-to-claim` 的 evidence_sufficiency（power/scale/replication） |
| A4 | **模块追踪没有「消融归属」** | `AlgorithmModule` 有 inputs/outputs，但没有「哪个模块是本方法的创新组件」 | P1 | `ablation-planner` 的 component 枚举 |
