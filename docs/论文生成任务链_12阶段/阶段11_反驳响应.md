# 阶段 11 · 反驳响应（对齐 SciForge Phase 14+，advisory / 人审）

> 定位：按 review 或拒稿信生成逐点反驳信。rebuttal 是法律文书——**不得承诺未做的实验**。该让步的让步，用证据回应，产出精确手稿改动。

## 1. 处理的问题（事实）

**"every claim of new evidence in the letter must be traceable to a registered artifact — a rebuttal is a legal brief, not a promise."**

**"Quote, then answer. Every point: verbatim quote → concession → evidence-backed response → exact manuscript change. Missing any segment = unfinished point."**

## 2. 输入

### 2.1 检索的知识节点
| 节点类 | 关键属性 | 来源 | 是否必须 |
|---|---|---|---|
| ReviewPoint | `axis / attack` | Phase 10 review | 必须 |
| Claim | `statement` | Phase 7e | 必须 |
| Evidence | `quote / paper_id / source` | 证据层 | 必须 |
| ExperimentArm | `kind / config / n_seeds` | Phase 7b | 必须（新证据凭证） |
| RunArtifact | `run_id / path / sha256` | Phase 7b | 可选（run 凭证） |
| RebuttalLetter | `claims`（本 skill 产出） | 本 skill | 必须 |

### 2.2 检索的 schema 定义
- `application/ReviewPoint.md`——`response` 字段回填（task-w）。
- `application/ExperimentArm.md`——实验矩阵 cell 完成与否的核对对象。
- `application/RunArtifact.md`——`run_id / kind(log/metric/file) / path / produced_by`（"新实验真的跑了"的凭证）。
- `application/Evidence.md`——`quote`（证据支撑句）。

### 2.3 输入产物文件
`AUTO_REVIEW.md`、`REVIEW_STATE.json`、`REVIEW_LEDGER.json`、`paper/main.tex` + `sections/*.tex`、拒稿信（可选）、`EXPERIMENT_MATRIX.json` + `EXPERIMENT_LOG.md`（gate 证据）。

## 3. Skills 转移函数

| skill | 角色 | 输入 → 输出 |
|---|---|---|
| `support/rebuttal` | Phase 14+ advisory，人审 | review/拒稿 → REBUTTAL_LETTER |

### 原始 prompt 原文（逐字）
- "Extract every atomic reviewer point... Number them `R1, R2, ...` and quote each verbatim. Do not paraphrase the accusation — the area chair compares quotes against the original."
- 四段式："For every point, in order: 1. **Quote** — the reviewer's sentence(s), verbatim, blockquoted. 2. **Concession** — concede factual errors and valid criticisms explicitly ('We agree; the original text was wrong/unclear...'). Never concede a load-bearing claim without evidence forcing it. 3. **Response** — evidence-backed rebuttal... No evidence → do not contest; concede or scope down instead. 4. **Manuscript change** — exact location (section + label/line)..."
- "No sarcasm, no irritation, no 'as the reviewer should have noticed'."
- "Disagree with evidence, not with the reviewer; every disagreement names the artifact that settles it."
- "The letter MUST NOT claim new experiments, results, or numbers were produced unless evidence exists in EXPERIMENT_MATRIX.json (cell completed) or EXPERIMENT_LOG.md (run logged)... Any promised-but-unrun work must be labeled **planned / pending** with its matrix cell ID."
- "Evidence or concede. A response without an artifact citation is a `wording` response in disguise; either find the evidence or concede."
- "Pending ≠ done. Planned work is labeled pending with its matrix cell; only logged runs may be asserted as done."
- "Max contested points per round: 3 — when contesting (rather than conceding), pick at most 3 points per draft round to argue back, the most impactful ones."

### 推理逻辑（解释）
逐字抽取 reviewer 原子意见编号 → 每点四段式（引用/承认/证据回应/精确改动）→ response_class 分类（experiment_redesign/pivot/kill/wording）→ 新证据必须有 EXPERIMENT_MATRIX 完成格或 EXPERIMENT_LOG run 记录 → 反驳配额每轮≤3。核心是"用产物凭证约束承诺"，杜绝学术诚信红线。

## 4. 输出

### 4.1 知识节点
- `ReviewPoint.response`（字段回填，task-w）、`RebuttalLetter.claims[]`（建议新增）、`Evidence.quote`

### 4.2 产物文件
`paper/REBUTTAL_LETTER.md`（固定名 deliverable）+ `paper/REBUTTAL_LETTER_{YYYYMMDD_HHmmss}.md`（版本历史）+ `.sciforge/MANIFEST.md` 追加一行。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| 新实验证明 | EXPERIMENT_MATRIX cell completed 或 EXPERIMENT_LOG run logged | — | 否则标 pending / 矩阵 ID |
| shrink 门 | wording-only | — | FAIL `shrinkage_only_response` → 重写 |
| contested 上限 | 每轮反驳点数 | ≤3 | 分批 |
| 无 review points | — | — | STOP（先跑 auto-review-loop） |
| KILL 级 | review 要求对核心主张 KILL 级响应 | — | 先跑 `/kill-argument`；若成立应改范围而非反驳 |
| anti-fantasy | 无证据的 "we have since run..." | — | 写入输出文件前拒绝 |

**有界回退**：KILL 级 → 转 `/kill-argument`（若成立 → scope revision）；无 review → 先跑 `/auto-review-loop`；camera-ready 已录用 → 不用。本 skill **不直接编辑** `paper/main.tex`——信只"描述"改动，应用改动是 `/paper-writing` 的职责（除非用户明确要求）。

## 6. 事实 / 解释 / 不确定
- **事实**：四段式模板、≤3 contested/轮、四 response_class、"pending≠done"、anti-fantasy gate、不编辑 tex。
- **解释**：把 rebuttal 归为"输出型只读能力"——它产出文书但不改变研究状态（区别于 paper-writing 的应用改动）。
- **不确定**：rebuttal 的 effort 表（draft rounds 1/2/3/5，stress tests 0-1/1/2/3）来自原文，引用时按 effort 档位标注。
