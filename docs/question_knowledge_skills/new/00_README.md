# 写论文必须回答的问题（重做版）

> 上一版把问题写成了「防 agent 出错的工程机制」（问题锚定会不会被悄悄改写、要不要做泄露审计）。
> 这一版纠正为：**做这篇论文本身必须回答的方法论问题** —— 这个领域认什么证据、
> 什么算贡献、实验要做到什么程度、论证链怎么搭、哪些错在这个领域是致命的。

## 为什么会有这个区别

| | 工程防错 | 科研方法论（本版） |
|---|---|---|
| 问的问题 | 题目会不会被悄悄改写？ | 这个领域用什么标准判断「成立」？ |
| 判据来源 | 流程完整性 | 学科共同体惯例 |
| 失败表现 | 产物缺失、hash 不一致 | 结论不被审稿人接受 |
| 谁关心 | 系统维护者 | 作者、审稿人、读者 |

工程机制仍然需要，但它是**实现手段**，不是「要解决的问题」本身。本版只写后者。
