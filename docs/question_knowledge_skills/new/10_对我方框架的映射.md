# 10 · 从方法论倒推：要抽什么、prompt 怎么改

前九份是「写论文必须回答的问题」，这一份是**倒推**：要回答它们，语义层里必须先有什么。

## 10.1 九个问题 → 必需字段

| 问题 | 必需字段 | 从哪抽 | 没有会怎样 |
|---|---|---|---|
| 属于哪种范式 | `Paper.paradigm` | E1（方法节+实验节写法） | 不知道该用哪套证据标准 |
| 认什么证据 | `Paper.evidence_type` | E1 | 不知道 pro/ve/supported 的边界 |
| 证据到什么程度 | `model_results[].seeds / sample_size / train_scale` + `Benchmark.protocol` | E3、E4 | 无法判断是 numerical 还是 qualitative |
| 什么算新 | `Paper.contributions[]`（每条含 why_not_before） | E1 | 无法做碰撞矩阵 |
| 实验够不够 | `Benchmark.protocol` + `metrics[].contribution_link` | E3 | 无法判断 baseline/消融是否齐 |
| 论证结构 | `Paper.section_map`（章节 → 论断） | E1 | 无法检查每个论断是否有支撑 |
| 领域坑 | `Paper.assumptions[]` + `Algorithm.limitations[]` | E2 | 无法判定 Type II/III 泄露 |
| 图表与引用 | `Figure.caption` + `RELATED_TO.context` | E5（新增 Figure 抽取） | 无法验证图注与引用上下文 |
| 审稿会怎么打 | 上述字段的组合 | — | 无法预演反驳 |

## 10.2 prompt 改动：从「加约束」改成「要求读出来」

上一版写的是禁令（不许编造 seed、不许用 unit 承载方差）。
这一版的核心是**让模型把论文里已有的方法论信息读出来**：

| 阶段 | 原来只问 | 现在还要问 |
|---|---|---|
| E1 | 研究什么问题、什么领域 | 这篇属于哪个范式？它的贡献靠什么说服人（证明/数字/系统/解释）？列出了哪几条贡献、每条为什么以前没人做？ |
| E2 | 方法名、机理 | 这个方法依赖什么前提才成立？哪个模块是论文声称的创新组件？ |
| E3 | 输入输出、指标 | 实验协议是什么（seed/划分/评测脚本）？每个指标度量哪个贡献？ |
| E4 | 数值 | 这个数值是几个 seed 的结果？样本量与训练规模？是主结果还是消融？ |
| E5 | 工具与公式 | 这条引用支撑了哪句话？被引论文的 DOI/venue 是什么？ |
| E6 | 继承关系 | 相比父方法，改进了哪条**前提**？ |

关键差别：前者问「有没有违规」，后者问「论文本身说了什么」——
前者靠检查，后者靠抽取。检查只能发现遗漏，抽取才能拿到事实。

## 10.3 三个立刻可做的改动

| 改动 | 工作量 | 收益 |
|---|---|---|
| E1 加 `paradigm` + `evidence_type` + `contributions[]` | 3 个字段，prompt +120 字符 | 后续所有判定有了标尺 |
| E4 加 `seeds` + `outcome_class` | 2 个字段，prompt +80 字符 | 能区分主/次结果与证据强度 |
| E3 加 `protocol` + `contribution_link` | 2 个字段，prompt +100 字符 | 能判断实验是否可重复、指标是否对口 |

三项合计约 300 字符，占当前 8395 的 3.6%，不影响既有 prompt 预算。

## 10.4 与旧版文档的关系

- 旧版（`../0*.md`）保留：它写的是**工程实现**（怎么冻结、怎么审计、怎么设门）
- 本目录（`new/`）是**方法论问题**（要回答什么、按什么标准回答）
- 两者是「做什么」与「怎么保证做到」的关系，不冲突

推荐先读本目录，再回旧版看实现手段。
