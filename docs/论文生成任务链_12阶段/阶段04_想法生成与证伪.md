# 阶段 04 · 想法生成与证伪（对齐 SciForge Phase 2 / 2.5 / 2.5b）

> 定位：以 gap 为锚生成 8–12 个想法，经六轴预筛 + 4 轮 MCTS 收敛；再对每个想法"先证伪后证明"，通过 5 个攻击向量筛掉基于不现实假设的 fake trick。

## 1. 处理的问题（事实）

- `idea-discovery`：**"never commit to a single idea before MCTS iteration completes — the first idea is rarely the best."** 想法必须是真科学洞见，不是"我们用方法 X 做 Y"的垃圾想法。
- `adversarial-falsification`：**"it's easier to spot why an idea is wrong than to prove it's right."** 每个进入推导的想法都必须被显式压力测试。

## 2. 输入

| 节点类 | 关键属性 | 来源 | 是否必须 |

### 2.2 检索的 schema 定义
- `application/ResearchGap.md`——`gap_type / statement / evidence / priority / source_papers`（每个晋升想法必须 anchor 到 gap-id）。
- `application/FailureMode.md` / `application/EvidenceNorm.md`——证伪与可行性判定的依据。
- `application/DataContract.md`——data-readiness 轴（输入/输出形式、样本量、模态）。
- `semantic/Paper.md`——`references.bib` 中已验证论文。

### 2.3 输入产物文件

### 原始 prompt 原文（逐字）

idea-discovery：
- "The non-negotiable goal: **never commit to a single idea before MCTS iteration completes — the first idea is rarely the best.**"
- "User hard requirement: ideas must not be written as garbage. An idea that is only 'we use method X to do Y', with no novel insight, no mechanistic contribution, no point of difference from existing work, is a garbage idea and must be eliminated."
- "Strictly forbidden: letting the LLM eliminate feasible options by subjective taste at the pre-screen stage."
- "MCTS iteration is mandatory. Do not commit to the first idea generated — the first idea is rarely the best. Always run ≥ 4 MCTS rounds."
- "The injected text starts with `[failed-ideas prompt injection]`"
- 4 视角 framing："We establish [outcome] by deriving [chain] under [assumptions]" / "We confirm [prediction] numerically via [sweep] in [regime]" / "We show [mechanism] implies [prediction] by [qualitative argument]" / "We recover [causal parameter] via [identification strategy] under [assumption]"
- 6 必填字段："One sentence: what is the scientific insight with which this idea surpasses existing work?" / "One sentence: relative to the 1-2 closest papers in references.bib, the concrete point of difference of this idea" / "One sentence: the core claim of this idea is falsifiable — which experiment/derivation outcome would refute it?"

adversarial-falsification：
- "For each candidate idea, execute 5 attack vectors to find its weakest point."
- "Try to construct a counterexample that would falsify the idea"
- "Search the literature specifically for evidence AGAINST the idea"
- "Never skip falsification. Every idea must be stress-tested before entering derivation."
- "Falsification is not rejection. A WEAKENED idea can be re-expressed and re-tested."
- "Search for contradiction, not confirmation. The default should be skepticism, not acceptance."

### 推理逻辑（解释）
gap 锚定 → 4 视角并行生成 8–12 想法 → 六轴预筛（novelty/feasibility/relevance/tractability/data-readiness/EG）→ 4 轮 MCTS（≥0.6 晋升，0.4–0.6 生子节点，<0.4 拒绝）→ 每想法 5 攻击向量证伪 → 存活者进阶段 5。反重复用 TF-IDF cosine >0.78 直接丢弃。

## 5. 门与有界回退

| 门 | 判据 | 阈值 | 失败去向 |
|---|---|---|---|
| 六轴预筛 | 任一轴 BLOCKED | — | MCTS 前淘汰 |
| EG 门 | ≥3 子维=0 | — | BLOCKED |
| 晋升门 | MCTS score | ≥0.6 晋升；<0.4 拒绝；0.4–0.6 生子节点 | border 重评 |
| gap 锚门 | 无 gap-id 且无正当 exploratory | 每轮 2 次 | relevance 封顶 0.5 |
| 反重复门 | TF-IDF cosine | >0.78 | discard（`duplicate_failed_idea`） |
| 证伪门 | assumption_health | ≥6 SURVIVE；4–6 WEAKENED；<4 FALSIFIED | WEAKENED 重构再测；FALSIFIED 拒绝 |
| 数据门 | 可用性 | ≥80% DATA_READY；<50% DATA_BLOCKED | 换数据或 theory-only |
| Type-A 门 | GPU 估算 ×1.5 + 4 项机械检查 | 任一 FAIL | 零成本淘汰 |
| 零晋升门 | 0 promoted | — | 放宽视角重生；第 2 轮仍 0 → 报告人类 |

**有界回退**：BA（实验证伪核心主张）→ 回 Phase 2 换想法，≤2 轮（全局共享），耗尽 → `BLOCKED + BA_EXHAUSTED`；in-phase 执行错误 → 相邻上游 phase，3 轮。

## 6. 事实 / 解释 / 不确定
- **事实**：MCTS ≥4 轮、0.6/0.4 阈值、cosine 0.78、5 攻击向量、assumption_health 6/4 分界、BA≤2 轮。
- **解释**：把"4 视角 × 6 轴 × 4 轮 MCTS"理解为既防"过早锁定"又防"主观口味淘汰"的双重保险。
- **不确定**：`auto-pipeline` 说 MCTS "4 rounds→约 2.5 rounds（40% reduction）"（某 effort 档），与 idea-discovery 的 "≥4" 存在档位差异——引用时应按 effort 配置区分。
