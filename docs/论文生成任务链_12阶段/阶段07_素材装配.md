# 阶段 07 · 素材装配（对齐 SciForge Phase 6a/6b/6c/7/8/9/10/11）

> 定位：全链最密集的节点加工区。把"离散的客观事实 + 实验结果"加工成"可写进论文的、带保真度和证据锚的素材包"。含 6 个子阶段：推导→实验→证据审计→不变量→结果转主张→绘图。

## 1. 处理的问题（事实）

- `theory-derivation`：**"Build an honest derivation package, not a fake polished theorem story."** / **"coherence matters more than elegance."**
- `experiment-execution`：**"Never invest full compute in an unvalidated idea. Toy first, gate check, then full."**
- `result-to-claim`：**"never inflate a claim beyond what the evidence supports — the external reviewer is the judge."**
- `unified-plotting`：**"Every DATA figure is reproducible... Every figure is vector... the caption is written AFTER the final render, never before."**

### 原始 prompt 原文（逐字，按子阶段）

**7a theory-derivation**
- "The non-negotiable goal: coherence matters more than elegance. Never fabricate a coherent derivation if the object, assumptions, or scope do not support one. Every step is SymPy-verified. Prefer reframing the derivation over overclaiming."
- "Do not start symbolic manipulation before this is fixed."
- "Never merge these categories without signaling the transition. If one part is only interpretive, do not present it as if it were mathematically proved."
- "Every nontrivial step is SymPy-verified. Do not hand-wave a step that SymPy could check. If SymPy is unavailable (engine: manual), flag every step as [not machine-verified] in the report."

**7b experiment-execution / ladder / sandbox**
- "One core claim, one test — do not bundle multiple hypotheses"
- "A FAIL toy experiment must not proceed to full experiment — this is the life-or-death verdict on the idea"
- "Keep tuning to force-rescue" is forbidden — when the toy has already falsified the core direction, tuning is stalling, not PIVOT
- "Reproduce the incumbent on the subset... No reproduction = no ladder."；"Decide the Critic state with the production function (do not eyeball)"
- "GOOD: strictly better | ENGINEER: tie/below-margin | BAD: worse"
- sandbox："The skill does not understand science — it only runs code and returns data."；"Errors are captured, not swallowed — failed operations return the full traceback"

**7c leakage-audit / logic-verification**
- "The claimed implications do not mathematically or logically follow from the stated assumptions."（Type I）
- "Use the LLM to evaluate: 'Does this implication follow from these assumptions?'"
- "If methods/METHOD_REGISTRY.md does not exist, ABORT and tell the user to run /method-registry first. Audit without registry is meaningless."
- "correctness matters more than declaring success. Never silently pass an argument with open gaps; never fabricate a fix."
- "Zero open FATAL or CRITICAL issues."；"Counterexample pass is mandatory for key lemmas. Log candidates even if none found."

**7d invariant-check**
- "a reviewer asks 'is this good?'; an invariant checker asks 'is this present and structurally valid?'."
- "If the Q-id is absent, verdict = FAIL (problem anchor lost). If a different Q-id is referenced, verdict = FAIL (problem drift)."

**7e ablation-planner / result-to-claim**
- "no claim crosses phase 10 without component-level evidence — which part of the method actually earns the result?"
- "Plan 5–6 ablations, one component each... hypothesis states the expected sign ('removing X drops accuracy ≥ …')."
- "Strict rule: GOOD iff strictly better; ties keep the old state (REFINE)."
- "Be honest. Do not inflate claims beyond what the evidence supports. A qualitative 'looks right' judgment does not support a 'proven' claim."
- "Never label a claim 'proven' without symbolic fidelity. Never label a claim 'supported' without at least numerical fidelity."
- "Negative results are never contributions"
- "Compute joint = T × D × A × L exactly — no rounding, no clamping, no weighted-average substitution."
- "UNSUPPORTED verdict → BLOCK the orchestrator: emit verdict: BLOCKED, reason_code: unsupported_claim_<weakest_dimension>, do NOT advance to Phase 11."

**7f unified-plotting**
- "specs missing claim/archetype are rejected."
- "if removing it loses no unique inference, it does not belong in the main figure."
- "the caption is written AFTER the final render, never before (a caption describing a figure that since changed is a visual lie)"
- "it describes the SCIENCE, never the pipeline"

### 推理逻辑（解释）
这是把语义层客观事实（Algorithm/Module/Benchmark/CodeFunction）"蒸馏"为应用层判定结果（Claim/Evidence/LeaderboardEntry/FigureAsset）的核心。每个 claim 都要走完"推导或实验 → 充分性检验 → 保真度定档 → TDAL 联合置信 → 三哈希锚定"五步，任何一维为 0 就封顶。

## 5. 门与有界回退（本阶段门最密集）

| 子阶段 | 门 | 阈值 | 失败去向 |
|---|---|---|---|
| 7a | PROOF_AUDIT | coherent→PASS；close-but→WARN/FAIL；incoherent→FAIL/BLOCKED | 缺 PROOF_AUDIT = chain break；重述/重构 |
| 7a | max_steps / tolerance | 50 / 1e-10 | 超限拒绝 |
| 7b | toy gate | core_claim_validated + seeds_used 必填 | FAIL→KILL/PIVOT；INCONCLUSIVE→1 retry→BLOCKED |
| 7b | KILL-or-PIVOT | negative 显著 + ≥2 seeds 同向；PIVOT≤2 | 超限 KILL |
| 7b | smoke gate | 1 step/1 batch，60s timeout，4 类失败码各 1 retry | 2 次失败→BLOCKED |
| 7b | 后台派发 | >15min / ≥5 组 / >1GB → 后台 | STATUS.json 每 60s 写 |
| 7b | recovery | ≤2 次 | 超限 BLOCKED |
| 7b | s2_ladder | ENGINEER≤2；ties never count | 耗尽→loopback L5/L7 |
| 7c | leakage | Type I LEAKY on primary / Type IV ESCAPE → FAIL | callback method-registry ≤3 轮 |
| 7c | logic | FATAL=INVALID+GLOBAL；MAX_REVIEW_ROUNDS=3 | 3 轮未过→UNRECOVERABLE_ARGUMENT |
| 7d | INV-G1 | Q-id 一致 + SHA256 相等 | FAIL → 回 Phase 0/1；换题须 KILL |
| 7e | ablation | 计划 5–6；decision=ablcritic；current_best 单调 | FAIL→补跑消融 |
| 7e | fidelity | primary≥numerical；proven 需 symbolic；supported 需 numerical | primary qualitative→REJECT；UNSUPPORTED→BLOCKED |
| 7e | sufficiency | ≥3 seeds(lite≥2)；effect>1×std；≥1 baseline；无 toy_overreach | 任一失败→降为至多 qualitative |
| 7e | TDAL | joint=T×D×A×L；任一维=0→至多 WEAK | weakest_dimension 必报 |
| 7f | A1–A11 审计 | panel 对齐 1.5pt；正文≥7 图<7 WARN <5 FAIL；缺架构图 FAIL | FAIL→按 suggested_fixes 修；同一 concern 3 次→重排 |

**有界回退汇总**：PIVOT→Phase 5 换方法（≤2）；KILL→Phase 2 换想法（人工检查点）；LEAKAGE callback→method-registry（≤3）；LOGIC FATAL contradiction→BA 回 Phase 2（≤2）；compile/smoke crash→Phase 6。

## 6. 事实 / 解释 / 不确定
- **事实**：所有阈值（50/1e-10、0.6/0.4、5–6 消融、T×D×A×L、≤2 PIVOT、≤3 callback、1.5pt、7/5 图）均为原始文档明文。
- **解释**：把 6 个子阶段按"事实→判定→可写素材"的依赖顺序排列（推导/实验产出 Evidence，审计给 verdict，转主张产出 Claim，绘图产出 FigureAsset）。
- **不确定**：`paper-writing` 提到 result-to-claim 是 MANDATORY，若未调用则 BLOCK paper writing；本阶段 7e 是它的实际执行点。另 `char_span`（Evidence）在 schema 中标注"待补"，阶段 12 审计精度受限。
